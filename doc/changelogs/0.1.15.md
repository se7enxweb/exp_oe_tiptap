# exp_oe_tiptap 0.1.15 (2026-10-26)

No class or setting changes; the skin a4 on a phone, and translations into 46 more languages.

## Added

- Added: Swahili (Kenya) translation, from ekked's pull request #12.
- Added: Translations into eighteen more administration languages: Hindi, Korean, Bosnian, Lower Sorbian, Estonian,
  Irish, Icelandic, Greenlandic, Latvian, Hungarian, Maltese, Romanian, Albanian, Slovak, Slovenian, Japanese, Greek
  and Finnish, from ekked's pull request #14.
- Added: Russian, Catalan, Serbian (Cyrillic and Latin), Bulgarian, Lithuanian, Portuguese (Portugal) and Afrikaans
  translations, from ekked's pull request #15.
- Added: Translations into seventeen languages from South Asia and Africa: Bengali, Urdu, Marathi, Telugu, Tamil,
  Gujarati, Kannada, Malayalam, Punjabi, Odia, Hausa, Amharic, Yoruba, Igbo, isiZulu, Somali and isiXhosa, from
  ekked's pull request #16.
- Added: Chinese translations in Simplified (chi-CN) and Traditional (chi-TW) script; chi-HK falls back to chi-TW,
  from ekked's pull request #17.

## Fixed

- Fixed: The toolbar sticks below admin4's fixed header and the sticky button bar of the edit form
  (`--a4-sticky-edge`, kept by admin4.js) instead of at `top: 0`, where both covered its first rows on a phone. In
  fullscreen it starts at the window's top. From ekked's pull request #11, as are the bubble menu and the three
  entries under Updated.
- Fixed: The bubble menu over selected text stays inside the text area; at the end of a line on a narrow screen its
  last button (link) was outside the editor.
- Fixed: ezinfo.php names the third-party Tiptap as 3.31.4 again (0.1.14 said 0.1.14), and package.json and
  package-lock.json carry the extension's version.
- Fixed: Compiling the editor template no longer logs "No such variable 'Skin'" for exp_oe_tiptap.ini: the
  lookups of Skin are dynamic.
- Fixed: Translations that contradicted their language guide: wrong meanings, glossary breaches, forms of address,
  typos and English left in the text (esl-MX, fre-FR, ukr-UA), from ekked's pull request #13.

## Updated

- Updated: Below 40rem the toolbar is one row that scrolls sideways instead of six or seven wrapped rows.
- Updated: On touch screens and below 40rem the toolbar, bubble and "+" buttons are 44px.
- Updated: On touch screens the dialog fields have 16px text, so a phone's browser does not zoom in on focus (the
  dialog is a child of `<body>`, outside admin4's own rule for `#page`).
